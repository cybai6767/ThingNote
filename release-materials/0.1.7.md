# 记物本 0.1.7

- 优化安装包：正式版开启代码与资源裁剪，图标改为按需保留，启动图标采用无损 WebP，清理未使用的直接依赖。
- 添加、编辑改为按项填写：名称、分类、价格、购买/过保/退役日期、保修月数、提醒、计算方式、备注和图片；支持滚轮选择，只填名称即可保存。
- 支持按时间、按次数或不计算均价；兼容未设置过保日期的物品及旧版备份。
- 列表和日历显示备注；设置 → 数据新增清理缓存。
- 概览分类取消长按拖拽和相关提示，过保筛选随当前日期更新。
- 应用内版本更新为 0.1.7。

同一份功能代码的正式 APK 从 13.36 MB 缩小到约 2.06 MB，减少约 84.6%。完整源码及图标原始设计仍保留，支持继续二次开发。

已通过正式版/调试版构建、64 项单元测试及 APK 签名校验。本次未进行真机界面测试。

支持 Android 8.0 及以上。正式版沿用原签名；更新前建议导出本地数据备份。

优化前恢复点：`before-apk-optimization-0.1.7`。
