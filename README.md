## 功能

- 概览：查看在保、即将过保、已过保和已处理物品，以及总资产、日均成本和分类金额。
- 添加：一句话识别物品、到期日期、金额及提醒时间，也支持快捷添加和手动填写。
- 我的：搜索、分类筛选、列表与日历视图，自定义分类和拖动排序。
- 设置：外观、提醒以及本地备份导出与恢复。

总资产统计所有未处理物品，包含已过保物品。单件日均成本为金额除以已持有天数，购买当天按 1 天；概览汇总可计算物品的日均成本。

## 数据

物品数据保存在本机。应用无账号、广告或云同步，建议定期导出本地备份。
